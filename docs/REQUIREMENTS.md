# 需求規格


> 2026-11-09 最新確認：運動順序為蛙跳 → 交互蹲跳 → 波比跳 → 伏地挺身 → 深蹲。第五組每輪後30秒繼續蹲著（靜態深蹲）。已更新畫面、語音及測試；下文歷史上的名稱／順序缺口已由使用者本次確認補齊，原程式碼仍未完整取回。

| 功能 | 驗收條件 |
|---|---|
| 課表 | 5 組 × 4 輪 × (30+30 秒)=1200 秒；40 階段，包含最後休息 |
| 組／輪順序 | 同組四輪後換下一組；第 5 組第 4 輪休息後完成 |
| 深蹲 | 運動標示深蹲；該組休息標示與語音為靜態深蹲 |
| 開始／暫停 | 開始不依賴音訊或常亮成功；暫停保留小數秒進度；繼續不重置 |
| 重置 | 回到第 1 組第 1 輪運動、30 秒、總剩餘 20:00，停止語音及常亮 |
| 動作／輪次切換 | 可選 5 組、1～4 輪、運動／休息；按切換後完整 30 秒；保持原執行狀態 |
| 上下輪 | 課表中的前／後一輪，從運動開始；可跨組；首尾限制於有效範圍 |
| 語音 | zh-TW；階段切換、最後 3 秒、完成；可關閉；不累積過期語音佇列 |
| 節奏 | Web Audio 合成，不需 MP3；128 BPM，音量 35% 起，可調與關閉 |
| 常亮 | 開始時嘗試請求；暫停、完成、重置釋放；失敗顯示原因但計時繼續 |
| 前景生命週期 | visibilitychange 隱藏時自動暫停；返回後手動繼續並重新請求常亮 |
| 可攜性 | 單 HTML 加可編輯來源；不需後端、CDN、GitHub 部署 |

動作資料不完整為已知缺口；不得將占位視為已完成原課表還原。語音與常亮在 iPhone ChatGPT 的可用性屬實機驗收，非純邏輯測試可證明。
