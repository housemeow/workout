# 後續開發待辦

1. **P0 原碼復原**：從可取得的原 HTML 或互動畫布匯出完整程式碼。使用者已說名稱在原碼內；先讀檔，不再請其重列。保存原檔，恢復五組名稱與順序，列出和重建版的差異。
2. **P1 真實環境驗證**：使用者自行在 iPhone ChatGPT 操作，填 IPHONE_WAKE_LOCK.md 的紀錄。優先釐清開始按鈕是否執行 JS，再測音訊與常亮。
3. **P1 動作資料穩定化**：以 `{id,name,restLabel}` 取代依 index 判斷深蹲，原順序改動時仍保留靜態深蹲。
4. **P2 設定保存**：評估 JSON 匯出／匯入，避免宿主儲存限制；不引入帳號或後端。
5. **P2 音訊品質**：採 Web Audio 前瞻排程改善128 BPM節奏；中文 voice 選擇及中斷恢復需實測。
6. **P2 使用體驗**：實機字級／觸控驗收；區分真正休息與靜態深蹲提示。

不在目前範圍：後端、帳號、追蹤分析、醫療或運動處方。任何「永遠不鎖屏」承諾必須排除，不以靜音影片等未驗證技巧宣稱成功。
