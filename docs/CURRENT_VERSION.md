## 已知限制

- 常亮可能因環境、電量、系統或文件可見性被拒絕／釋放。僅回到前景時自動重試，沒有強制保證。
- 暫停以最後更新的整秒保存，可能有小於約一秒的差異；本次不改原邏輯。
- 背景音訊或回呼可能被系統暫停；返回後會跳到實際經過的課表位置。
- 首輪運動開始後立即暫停可能顯示「準備開始」，沿用原版。
- 手機聲音、觸控、視覺與常亮尚未實機驗收。

技術參考：[Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)。
