# HIIT 20 分鐘運動計時器

網站：https://housemeow.github.io/workout/hiit.html

2026-11-09 使用者提供 `HIIT_運動計時器_修復版.html`，並確認「這個才是對的」。目前網站直接發布此原檔，取代先前的需求重建版。這是使用者確認的修復版檔案，不另宣稱是最後 ChatGPT 內嵌產物。

## 目前課表與功能

- 蛙跳 → 分腿跳 → 波比跳 → 伏地挺身 → 深蹲（名稱依原檔）。
- 各4輪；運動30秒＋休息30秒，共20分鐘，含最後休息。
- 深蹲休息時繼續維持深蹲，畫面與語音為「深蹲停留」。
- 動作／輪次下拉切換、動作卡、上一輪／下一輪。
- 同一按鈕開始／暫停／繼續，完成可再做一次；從頭重置。
- 原版128 BPM合成電子節奏、預設35%音量、中文語音與倒數提示。
- 開始時嘗試取得常亮；暫停、完成、重置時釋放；失敗不影響倒數。

## 原檔行為與限制

原檔第二組為「分腿跳」，不是先前口述的「交互蹲跳」。本次依使用者最新確認原樣保留。原版切至背景不自動暫停，返回後按經過時間更新倒數，並在執行中重新嘗試常亮。系統可能限制背景音訊／計時回呼；無法保證iPhone不鎖屏。

驗證是Node模擬DOM／時鐘，不代表手機聲音、畫面或常亮已完成實機驗收。使用者自行操作瀏覽器。

## 檔案與開發

| 路徑 | 用途 |
|---|---|
| src/hiit.html | 唯一現行網站來源，完整HTML/CSS/JS |
| original/HIIT_運動計時器_修復版.html | 使用者上傳原檔，保持不變作為比對依據 |
| build.py | 原樣複製src至public/hiit.html，產生首頁導向 |
| tests/original.test.cjs | 現行原版的6項自動測試 |
| docs/ | 現行來源、架構與驗證說明 |
| archive/rebuilt/ | 已停用的重建版來源、測試、文件與舊證據 |
| HANDOFF.md | 新session交接起點 |

```sh
node --test tests/*.test.cjs
python3 build.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory public
```

自行開啟 http://localhost:8000/hiit.html。main推送後GitHub Actions測試、建置並只發布public/；封存與原檔資料不作為網站產物。

後續若明確要求改原版，編輯src/hiit.html並同步調整逐位元組一致性測試與來源文件；不得覆寫original快照或繼續宣稱修改版與原檔完全一致。
